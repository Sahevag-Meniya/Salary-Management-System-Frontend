DIAGRAM 3: PAYROLL CALCULATION & FORMULA FLOW
--------------------------------------------------------------------------------

                     +---------------------------------------+
                     |        HR MANAGER ENTERS INPUT        |
                     |         Basic Salary ($ / ₹ / €)      |
                     +---------------------------------------+
                                         │
                   ┌─────────────────────┴─────────────────────┐
                   │                                           │
                   ▼                                           ▼
      +─────────────────────────+                 +─────────────────────────+
      |  EARNINGS & ALLOWANCES  |                 |  STATUTORY DEDUCTIONS   |
      +─────────────────────────+                 +─────────────────────────+
      | HRA = 40% of Basic      |                 | PF = 12% of Basic       |
      | DA  = 10% of Basic      |                 | Professional Tax (Fixed)|
      | Conveyance (Fixed)      |                 | Health Insurance (Fixed)|
      | Medical (Fixed)         |                 | TDS / Income Tax Slabs  |
      | Special Allowance       |                 +─────────────────────────+
      +─────────────────────────+                              │
                   │                                           │
                   ▼                                           ▼
      +─────────────────────────+                 +─────────────────────────+
      |      GROSS SALARY       |                 |    TOTAL DEDUCTIONS     |
      |   Basic + Allowances    |                 |   PF + Tax + Insurance  |
      +─────────────────────────+                 +─────────────────────────+
                   │                                           │
                   └─────────────────────┬─────────────────────┘
                                         │
                                         ▼
                     +---------------------------------------+
                     |        INVARIANT CHECK & GUARD        |
                     |      Is Deductions <= Gross Salary?   |
                     +---------------------------------------+
                                    │         │
                           (NO)     │         │    (YES)
            ┌───────────────────────┘         └────────────────────────┐
            ▼                                                          ▼
  +─────────────────────────+                              +─────────────────────────+
  |    REJECT TRANSACTION   |                              |   NET TAKE-HOME PAY     |
  |  Throw 400 Bad Request  |                              | Gross - Total Deductions|
  | (Deductions > Gross)    |                              +─────────────────────────+
  +─────────────────────────+                                          │
                                                                       ▼
                                                           +─────────────────────────+
                                                           | 2-DECIMAL QUANTIZATION  |
                                                           | round(value * 100) / 100|
                                                           +─────────────────────────+
                                                                       │
                                                                       ▼
                                                           +─────────────────────────+
                                                           |   PERSIST TO DATABASE   |
                                                           |   MySQL Decimal(12, 2)  |
                                                           +─────────────────────────+
